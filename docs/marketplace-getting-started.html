OpenLinker helps you open web links or local files based on your current project, module, or file.

How to use

  1. Open a project, module, or file in your JetBrains IDE.
  2. Run OpenLinker from Tools > OpenLinker or click the OpenLinker button in the top toolbar.
  3. If only one rule is enabled, it opens immediately. If multiple rules are enabled, you can choose the one you want to open.
  4. Regular links open in your browser. file:// links reveal the target file or folder in your system file manager.

How to set it up

  1. After installing or updating the plugin, restart your IDE.
  2. Go to Settings > Tools > OpenLinker.
  3. Add a rule, then set its name, URL template, and whether it should be enabled.
  4. If a project needs a special URL, enable the project override in the rule editor and enter that project's URL template.
  5. Use placeholders like ${PROJECT_NAME}, ${MODULE_NAME}, ${FILE_NAME}, and ${FILE_PATH} to build links from the current IDE context.
  6. Click Apply or OK to save your changes.

You can also import or export rules from the settings page if you want to reuse them on another machine or share them with your team.
